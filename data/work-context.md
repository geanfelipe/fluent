# Work Context

> **PRIVACY RULE:** never put client names, company names, internal system names, colleague names, nationalities or accents, or any other detail that could identify the learner's client in this repository. Use generic labels ("the lead", "a teammate", "the legacy import"). Keep real names in the conversation only.

## Role
- Software developer (Java), working remotely on a financial-systems project with an international team.
- English: B2, target C1 by July 2027. Main need: meetings (stand-ups, technical sessions, 1:1s with the lead).
- Listening practice: colleagues with varied English accents → ask for clarification without making people repeat everything.

bracing for · band-aid · overkill · edge case · backfill · fallback · baseline · break (reconciliation break) · double counting · check in (code) · toggle · rollback · piggyback on · scope creep

## Real mistakes from meetings (drill these)
| Said | Correct | Type |
|---|---|---|
| Can you explain me this again? | Could you explain that to me again? | verb pattern: explain **something to someone** |
| used on production | used **in** production | preposition |
| refactory plan | **refactoring** plan | word form |
| This CSV process is used…? | **Is** this CSV process used…? | questions need an auxiliary (do/does/is/are/can) |

## Functional phrases to teach
- Asking for clarification without making people repeat everything.
- Paraphrasing to confirm understanding.
- Confirming action items at the end of a call.
- Pushing back politely, with evidence.
